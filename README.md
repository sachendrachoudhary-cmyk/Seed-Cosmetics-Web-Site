# Seed Cosmetics Web Site

> **Care Begins Here.**  
> Official E-Commerce Website & Commerce Engine for Seed Cosmetics ([www.seedcosmetics.in](https://www.seedcosmetics.in/)).

Mass-premium Indian personal-care D2C platform with botanical science formulation, Razorpay payment processing, full Admin Commerce CMS, Google SEO architecture, and AI Search (GEO) discoverability.

## 🌿 Core Architecture
- **Frontend**: Next.js / React (SSR/SSG, Tailwind CSS, Schema.org JSON-LD, Mobile-First Luxury Botanical UI)
- **Backend**: Node.js + Express.js REST API (Modular Controllers, Zod Schemas, RBAC Security)
- **Database**: MongoDB + Mongoose (14 collections, indexes, stock tracking, audit logs)
- **Payments**: Razorpay (Server-calculated orders, HMAC SHA-256 verification, Idempotent webhooks)
- **SEO & GEO**: Pre-rendered public HTML, dynamic XML sitemaps, robots.txt with `OAI-SearchBot` allow rules, canonicals, 301 redirects
- **Admin Suite**: Comprehensive commerce control centre (Dashboard, Products, Variants, Bullet Points Builder, Pricing, Coupons, Inventory, Orders, Content CMS, SEO Quality Gates)

## 🚀 Getting Started

### Prerequisites
- Node.js >= 18.0.0
- npm >= 9.0.0
- MongoDB instance (or automated in-memory development database)

### Installation & Run
```bash
# Clone the repository
git clone https://github.com/sachendrachoudhary-cmyk/Seed-Cosmetics-Web-Site.git
cd Seed-Cosmetics-Web-Site

# Install dependencies
npm run install:all

# Run development servers
npm run dev
```
